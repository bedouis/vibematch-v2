# Screenshots

`vibematch-ui.png` is a real screenshot of the running app (the Q4 search: *peaceful, relaxing rock*, live Gemini, 5,000-track catalog). It is referenced from the main [README](../README.md#running-the-streamlit-app).

To replace it or add another:

1. Start the app: `.venv/bin/python -m streamlit run app.py` (with `GEMINI_API_KEY` set; see the main [README](../README.md#gemini-api-configuration)).
2. Run a search, for example *Relaxing ambient music for reading*.
3. Save a screenshot of the browser window as `assets/vibematch-ui.png`.
4. Reference it from the main README, for example: `![VibeMatch 2.0 search results](assets/vibematch-ui.png)`.

Do not include real API keys or personal information in a screenshot. The text exports of the five real live searches are in [`docs/evidence/live/`](../docs/evidence/live/README.md).
