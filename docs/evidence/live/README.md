# Live Gemini UI exports (Q1–Q5)

These are the original Markdown exports provided by the project tester from VibeMatch 2.0 Streamlit result pages. Contents are preserved byte-for-byte.

- `query1.md`: UI output for ambient/relaxing search
- `query2.md`: UI output for workout search
- `query3.md`: UI error for rejected interpretation
- `query4.md`: UI output for peaceful rock search
- `query5.md`: UI no-interpretation message for zydeco search

Limitations: Streamlit exports **do not include the originally typed query text**, raw Gemini response JSON, model usage, response timestamps, or unique track IDs. Query text in `docs/EVALUATION.md` was manually recorded by the tester. These files corroborate what the UI displayed, not end-to-end API payloads or subjective listening relevance. URLs pointing to `localhost:8501` are local-only UI anchors.
